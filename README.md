# Shared Moving System

A Java application that manages a shared moving service, developed as the final project for the Data Structures course at Universidad Nacional del Comahue. The system is built around custom-implemented data structures.

## Overview

The system manages clients, cities, routes between cities, and moving requests. 

## Data Structures

| **AVL Tree** (custom) 
| **AVL Dictionary** (custom)
| **Graph** (custom, adjacency list) 
| **One-to-Many Map** (custom, AVL-based) 
| **Linked List** (custom) 
| **HashMap** (Java standard library) 

## Features

Register / remove clients
Register / remove cities and routes
Register moving requests
Query routes or requests
Generate listings or reports
Reads initial data from a text file (cargaInicial.txt)


## Technologies

Java
NetBeans / Maven
